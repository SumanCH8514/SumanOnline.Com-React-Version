## 🌟 Overview

**SumanOnline** is a high-performance, modern web application built with React and Vite. It serves as a comprehensive digital hub showcasing development services, portfolio projects, client testimonials, interactive account portals, and dynamic multi-gateway UPI payment integrations.

Designed with modern UI/UX principles, seamless transitions, dark/light theme switching, and responsive design for both desktop and mobile platforms.

---

## ✨ Features

- **⚡ Blazing Fast Architecture**: Powered by Vite and React 19 for instant hot-module replacement and optimized bundle delivery.
- **🎨 Dynamic Theme Switching**: Seamless dark and light mode toggle with smooth CSS variable transitions.
- **💳 Multi-Gateway UPI Payment Hub**: Interactive payment card supporting Personal Savings (SBI) and Business Gateways (Paytm, BharatPe, Google Pay, PhonePe) with dynamic QR code generation.
- **🎬 Fluid Animations**: Smooth page transitions and interactive micro-animations powered by Framer Motion.
- **📱 Fully Responsive**: Custom mobile drawer navigation, responsive grids, and adaptive typography.
- **🔐 Auth State Management**: Localized authentication context supporting login, registration, and user profiles.
- **💼 Service & Project Portfolios**: Filterable service catalogs and interactive portfolio showcase cards.

## 🚀 Getting Started

### Prerequisites

Ensure you have Node.js installed on your system:
- **Node.js**: `v18.0.0` or higher
- **npm**: `v9.0.0` or higher

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SumanCH8514/SumanOnline.Com-React-Version.git
   cd SumanOnline.Com-React-Version
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to `http://localhost:5173` to view the application.
